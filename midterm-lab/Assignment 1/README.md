# Royal Tag Website Clone

A simple clone of the Royal Tag clothing website I made while learning HTML and CSS.

## What's Inside
- HTML and CSS only
- Responsive design (works on mobile and desktop)
- Hamburger menu for small screens
- Product gallery

## How to Run
Just open `index.html` in your browser!

## What I Used
- HTML5
- CSS3
- Bootstrap
- Font Awesome
